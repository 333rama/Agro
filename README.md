## 🎯 What is this Project?
**AgroDrishti-Lite** is a high-performance, cross-platform mobile application built using **Flutter** and **Dart**. It acts as an AI-powered agricultural monitoring hub and live IoT telemetry dashboard. Designed specifically to blow away the reviewers at tech meetups and secure your entry pass instantly!
### ✨ Key Features:
 * 📊 **Live Sensor Telemetry Dashboard:** Real-time mock monitoring for soil moisture, temperature, humidity, and AI health index.
 * 📸 **AI Leaf Scanner Interface:** Futuristic machine vision simulator for detecting crop health patterns.
 * 👨‍💻 **Developer Profile Tab:** Showcases your technical expertise, clean mobile architecture, and developer identity.

## ⚙️ How It Works (Technical Architecture)
 1. **Frontend UI:** Built with Flutter's reactive widget tree (StatelessWidget and StatefulWidget), ensuring smooth transitions and a modern Material Design interface.
 2. **State Management & Navigation:** Utilizes BottomNavigationBar to seamlessly switch between the **Dashboard**, **AI Scanner**, and **Developer Profile** tabs.
 3. **Telemetry Integration:** Displays simulated live readings (Soil Moisture, Temperature, Humidity, and AI Health Index) inside dynamic card grids with clean gradients and shadows.
## 🛠️ Step-by-Step Guide: How to Run and Push to GitHub
Copy and paste these exact commands into your terminal or command prompt. No guesswork, 100% working!
### Step 1: Initialize Git and Push to GitHub
Open your terminal inside the project folder (agro_drishti_lite) and run these commands one by one:
```bash
# 1. Initialize git repository
git init

# 2. Add all project files
git add .

# 3. Commit with a cool message
git commit -m "🚀 Initial commit: AgroDrishti-Lite Flutter app ready for takeoff"

# 4. Rename default branch to main
git branch -M main

# 5. Connect to your GitHub repository (Replace with your actual GitHub username)
git remote add origin https://github.com/your-github-username/agro-drishti-lite.git

# 6. Push your code to GitHub
git push -u origin main

```
### Step 2: How to Run the App Locally on Your Computer
Want to test it before showing off? Run these commands in your terminal:
```bash
# Get all required flutter packages/dependencies
flutter pub get

# Run the app on your connected device, emulator, or Chrome browser
flutter run

```
