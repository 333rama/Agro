# AgroDrishti-Lite 🌾📱

A high-performance, cross-platform mobile application built using **Flutter** and **Dart** for agricultural AI diagnostics and live IoT sensor telemetry. Designed specifically for presentation at GDG Bangalore Flutter Meetup.

## Features
- **Interactive Dashboard**: Real-time mock telemetry monitoring for soil moisture, temperature, humidity, and AI health index.
- **AI Leaf Scanner**: Simulated machine vision interface for detecting crop diseases.
- **Modern Material Design**: Clean green color scheme with custom cards, gradients, and bottom navigation.

## Getting Started
1. Ensure Flutter SDK is installed.
2. Run `flutter pub get` to install dependencies.
3. Run `flutter run` to launch the app on your connected device or emulator.
